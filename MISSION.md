# Mission: Menguasai Kotlin dari Dasar untuk Pengembangan Aplikasi Android

## Why
Membangun fondasi pemrograman Kotlin yang solid dan idiomatik dari level pemula hingga siap mengembangkan aplikasi Android modern (Jetpack Compose & Android SDK), memanfaatkan latar belakang pemrograman Python dan JavaScript untuk mempercepat pemahaman konsep statis vs dinamis.

## Success looks like
- Memahami sintaks dasar, sistem tipe, dan fitur utama Kotlin (val/var, null safety, OOP, functional programming, coroutines).
- Mampu menyelesaikan tantangan pemrograman dan logika menggunakan Kotlin secara mandiri.
- Mampu membuat aplikasi Android fungsional pertama menggunakan Kotlin dan Android Studio / Jetpack Compose.
- Memahami perbedaan paradigma antara dynamic typing (Python/JS) dan static type system Kotlin.

## Constraints
- Format pembelajaran terstruktur bertahap: direktori per modul (`modul1`, `modul2`, dst.) dengan 2 file utama (`materi.md` dan `soal.md`).
- Pembelajaran disesuaikan dengan zona perkembangan terdekat (memanfaatkan analogi Python & JavaScript untuk percepatan konsep).
- Latihan bertahap dari logika dasar, OOP, Kotlin modern (lambdas, collections, null safety), hingga integrasi Android.

## Out of scope
- Backend Kotlin mendalam (Ktor/Spring Boot) untuk saat ini, fokus diarahkan ke Android.
- Multiplatform iOS/Desktop (KMP) sebelum dasar Android dan Kotlin dikuasai dengan matang.
