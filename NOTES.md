# Notes & User Preferences

- **Tujuan Utama**: Membangun aplikasi Android menggunakan Kotlin.
- **Prior Knowledge**: Pernah belajar Python dan JavaScript.
- **Format Belajar**:
  - Terstruktur per modul dalam direktori (`modul1/`, `modul2/`, dst.).
  - Setiap modul terdiri dari 2 file Markdown: `materi.md` (penjelasan konsep & contoh) dan `soal.md` (latihan/tantangan untuk dikerjakan).
  - Feedback loop: Pengguna membaca materi, mencoba kode, mengerjakan soal, lalu kita bahas dan periksa bersama sebelum lanjut ke modul berikutnya.
