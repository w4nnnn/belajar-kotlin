# Kotlin & Android Resources

## Knowledge

- [Official Kotlin Documentation](https://kotlinlang.org/docs/home.html)
  Dokumentasi resmi JetBrains untuk bahasa Kotlin. Referensi utama sintaks, null safety, OOP, dan standard library.
- [Kotlin Tour - Kotlin Official Tutorial](https://kotlinlang.org/docs/kotlin-tour-welcome.html)
  Panduan cepat resmi untuk pemula dan programmer yang berpindah dari bahasa lain.
- [Android Developers: Kotlin Fundamentals](https://developer.android.com/courses/kotlin-android-fundamentals/overview)
  Dokumentasi dan course resmi dari Google Android Developers untuk pengenalan Kotlin spesifik Android.
- [Kotlin for Python / JavaScript Developers Comparison](https://kotlinlang.org/docs/faq.html)
  Panduan transisi bagi developer dengan latar belakang dynamic language.

## Wisdom (Communities)

- [Kotlin Community / Slack & Forum](https://kotlinlang.org/community/)
  Komunitas resmi pengguna Kotlin dunia untuk berdiskusi tentang bahasa dan ekosistem.
- [r/Kotlin](https://reddit.com/r/Kotlin) & [r/androiddev](https://reddit.com/r/androiddev)
  Subreddit aktif untuk diskusi seputar best practices, tips, arsitektur, dan tanya jawab.
- [Komunitas Kotlin & Android Developer Indonesia (Telegram / Discord)](https://t.me/kotlin_id)
  Komunitas lokal untuk berjejaring dan berdiskusi seputar dunia kerja dan perkembangan Android/Kotlin di Indonesia.
