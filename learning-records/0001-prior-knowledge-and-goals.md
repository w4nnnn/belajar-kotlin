# Prior Knowledge and Learning Goals

Pengguna memiliki latar belakang pemrograman dasar di Python dan JavaScript, dengan tujuan utama membangun aplikasi Android menggunakan Kotlin.

## Implications
- Konsep dasar pemrograman (variabel, percabangan, perulangan, fungsi dasar, array/list, objek) tidak perlu dijelaskan dari nol secara filosofis, melainkan difokuskan pada perbedaannya di Kotlin (static typing, type inference, `val` vs `var`, null safety).
- Analogi dengan `const`/`let` di JS dan f-strings di Python dapat digunakan untuk mempercepat retensi.
- Pembelajaran menggunakan format modular direktori (`modul1/materi.md`, `modul1/soal.md`) sesuai permintaan pengguna.
